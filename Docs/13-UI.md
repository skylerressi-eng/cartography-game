# System 13 — UI architecture

The C++ provides three abstract base widgets. Designers extend each
in BP and lay out the visuals.

## Widget hierarchy

```
ACartographyPlayerController
├─ HUDClass         → BP_HUD       : extends UHUDWidget
├─ FieldMapClass    → WBP_FieldMap : extends UUserWidget (System 2)
├─ NotebookClass    → WBP_Notebook : extends UUserWidget (System 3)
├─ InkingClass      → WBP_Inking   : extends UUserWidget (System 4)
└─ PauseMenuClass   → WBP_Pause    : extends UUserWidget
```

## BP_HUD

Inherit from `UHUDWidget` (the C++ base). Add child widgets named
exactly:

- `Stamina_Bar`        — Progress Bar
- `Ink_Bar`            — Progress Bar
- `Time_Text`          — Text Block
- `Region_Text`        — Text Block
- `Prompt_Text`        — Text Block (interaction prompt, e.g. "E - Sit")
- `TutorialHint_Text`  — Text Block (small italic at bottom)

`UHUDWidget::NativeTick` automatically reads stamina, ink, time,
region and tutorial hint. No event graph wiring needed.

## BP_Compass

Inherit from `UCompassWidget`. Add a single Image named `Arrow_Image`
pointing up. The C++ rotates it opposite the camera yaw each tick.

Place a `BP_Compass` instance inside `BP_HUD`'s top-right corner,
visibility bound to `IsUnlocked("Compass")`.

## BP_DiscoveryToast

Inherit from `UDiscoveryToastWidget`. Add `Title_Text` and
`Subtitle_Text`. Implement `OnShow` (slide-in animation) and
`OnHide` (fade-out animation).

To show one from BP:
```
Create Widget (BP_DiscoveryToast) → Show("Old Beacon", "in north cape", 3.0)
```

Subscribe from `UDiscoveryLog::OnDiscovery` to fire toasts automatically.

## Pause menu

Extend `UUserWidget`. Buttons:
- **Resume** → `PlayerController.TogglePauseMenu()`.
- **Save** → `Subsystem(SaveSlotManager).QuickSave(Pawn, TOD)`.
- **Load** → list slots from `SaveSlotManager.ListSlots()`.
- **Settings** → push `WBP_Settings`.
- **Quit to Menu** → `Open Level (MainMenu)`.

## Settings panel (WBP_Settings)

Read/write `UCartoUserSettings::Get()`. Sliders for volumes, mouse
sensitivity, UI scale. Toggle for invert-Y, accuracy hints,
compass visibility. After change → `Settings.SaveAndApply()`.
